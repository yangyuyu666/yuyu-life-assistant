# Yuyu Life Assistant

一个简洁、离线优先的 Android 生活助手，包含待办、记账、聊天式备忘录和统一设置功能。应用使用“ai桶桶”云朵猫图片作为启动封面，并使用“桶桶图标”作为桌面启动图标。

## 已实现功能

### 待办

- 添加待办并选择精确到分钟的截止日期与时间（deadline）
- 左滑事务卡片删除，右滑修改截止日期与时间
- 长按进入多选模式，可全选并一次删除多项；返回键退出多选
- 按截止日期排序，并醒目标记已逾期待办
- 支持关闭、普通、强化、重复和闹钟式五档提醒；删除待办会自动取消提醒
- 显示事务总数量
- 数据保存在本机 Room 数据库

### 记账

- 添加收入或支出，并可选择记账日期
- 金额、可自定义分类和备注
- 可选择任意一天，查看当日明细与收支汇总
- 可选择任意月份，查看当月流水与总体收支
- 支持前后切换日期、月份
- 可按收入或支出分类筛选明细与汇总
- 左滑流水卡片删除记录
- 金额以“分”为单位存储，避免浮点误差

### 设置

- 独立的统一设置页，作为所有管理功能的入口
- 当前可设置待办在截止前多久提醒：到点、提前 5/15/30 分钟、1/3 小时或 1 天
- 可选择不提醒、普通提醒、强化通知、重复提醒或闹钟式提醒
- 重复提醒每 5 分钟一次、共 3 次；闹钟式提醒可关闭或 5 分钟后再次提醒
- 精确闹钟和全屏提醒需要用户在 Android 系统设置中授权；未授权时自动使用普通提醒
- 修改提醒方式或提前时间后会自动重新安排全部待办提醒
- 可分别新增、重命名和删除收入/支出分类；已有账目使用的分类不能删除
- 可从手机相册或文件选择待办、账本页面的背景图
- 关闭自定义背景后恢复纯色界面，同时保留已选择图片

### 备忘录

- 新建可改名的备忘录会话，像给自己发消息一样持续记录
- 支持多行文字以及图片、视频、音频、PDF、文档和压缩包等文件
- 一次可以选择多个文件，每个文件生成一条带独立时间记录的消息
- 图片可在应用内预览，其他文件交给手机中支持该格式的应用打开
- 长按文字可复制或删除，长按文件可删除并同时清理应用内副本
- 会话列表按最近活动时间排序；左滑并确认后删除整个会话及其附件
- 每条消息保存完整时间，聊天界面按日期或五分钟间隔显示时间
- 备忘录及附件仅保存在应用私有空间，覆盖升级会保留，卸载应用会删除
- 不限制单个附件大小，但实际可用容量受手机剩余内部空间限制

## 技术方案

- Kotlin
- Jetpack Compose + Material 3
- ViewModel + StateFlow
- Room
- Gradle Wrapper
- GitHub Actions 自动测试并构建固定签名的 Release APK

代码按职责拆分为 `domain`、`data`、`ui` 和 `util`，待办、记账和备忘录各自拥有独立的状态、ViewModel、页面和 UI 组件。备忘录的数据库访问、附件复制和界面展示也分别实现，避免把文件操作堆入页面代码。

## 云端构建 APK

推送到 `main` 后，GitHub Actions 会运行：

```bash
./gradlew testDebugUnitTest connectedDebugAndroidTest assembleRelease
```

构建成功后，在仓库的 **Actions → Build Android APK → Artifacts** 中下载 APK。

## 固定签名与 GitHub Secrets

Release APK 使用长期 JKS 密钥签名，后续版本必须始终使用同一密钥才能覆盖升级。密钥不得提交到公开仓库，并且必须妥善备份；密钥丢失后无法发布可覆盖安装的新版。

在仓库的 **Settings → Secrets and variables → Actions** 中添加：

- `YUYU_SIGNING_KEY_BASE64`：JKS 文件的 Base64 文本
- `YUYU_KEYSTORE_PASSWORD`：密钥库密码
- `YUYU_KEY_ALIAS`：密钥别名
- `YUYU_KEY_PASSWORD`：私钥密码

本机生成的密钥和待填写内容保存在仓库外的 `Documents/yuyu-life-assistant-signing` 文件夹中。Secrets 未配置完整时，云端构建会明确失败，不会回退为临时 Debug 签名。

`0.3.0` 及更早版本使用了无法恢复的临时签名，因此安装 `0.4.0` 前需要最后卸载一次旧版；从 `0.4.0` 开始可以直接覆盖升级。`0.6.1` 沿用 Room v5，可覆盖安装 `0.6.0`，并保留待办、账目、分类、设置、背景和备忘录数据。

应用关闭 Android 自动云备份和设备迁移备份。备忘录中的文件会复制到应用私有目录，因此原文件移动或删除后仍能打开；卸载应用会同时删除数据库与附件，本版不提供云同步、导出或恢复。
